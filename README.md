# UIUXAtlas

다양한 UI/UX 디자인 패턴과 애니메이션, 인터랙션 기법을 직접 체험하고 비교할 수 있는 인터랙티브 도감.

**공개 사이트:** https://oyueo-mm.github.io/UIUXAtlas/

## v1.3 — 기존 24개 카테고리 안에서 264개 도감

### 핵심 기능

- 독립된 홈 / 도감 / 카테고리 / 즐겨찾기 화면, 브라우저 뒤로 가기와 직접 링크
- 홈의 **2×2 애니메이션 카드가 순차적으로 교체**되며, 수동 넘기기/자동 전환 일시정지 제공
- 264개 기법의 자체 구현 시연과 한국어 설명, 사용 상황 및 주의점
- 상세 화면의 재생, 정지, 다시 재생, 배속 제어
- 텍스트·항목 검색, 필터, 즐겨찾기 로컬 저장
- 입력·선택·미디어·차트·쇼핑·레이아웃 등 **다양한 상세 인터랙션 컨트롤**
- 화면 밖 애니메이션 일시정지 및 접근성 동작 줄이기 고려
- 모바일 반응형, 서버·로그인 없이 GitHub Pages 정적 배포

일부 모바일 제스처·시스템 공유·동영상 플레이어·차트는 작동 원리를 보여주는 **교육용 모의 시연**입니다. 시연에서 표시하는 금액·재고·성과 수치는 예시이며 실제 데이터가 아닙니다. 접근성 미리보기도 실제 보조기술 테스트를 대체하지 않습니다.

### 파일 구조

- `index.html`: 홈 및 도감 화면, 기본 UI
- `app.js`, `styles.css`: 기존 도감 로직과 레이아웃
- `expansion-data.js`, `expansion-demos.js`, `expansion-controls.js`, `expansion-styles.css`: v1.1 확장
- `more-data.js`, `more-demos.js`, `more-controls.js`, `more-styles.css`: v1.2 확장
- `within-data.js`, `within-demos.js`, `within-styles.css`: 기존 카테고리에 추가한 48개 신규 기법
- `within-controls.js`, `within-runtime.js`: 신규 기법의 실제 조작·드래그 선택·카운트 애니메이션
- `tests/check-expansion.cjs`, `tests/check-within.cjs`: 기존 216개 보존과 신규 48개, 24개 분류 유지 검증
- `tests/check-within-browser.cjs`: 신규 기법의 실제 Chrome 조작 검증
- `tests/smoke.cjs`: Chrome 화면 전환·홈 순환·상세 조작 테스트
- `tests/audit-motion.cjs`: 애니메이션 존재·유효성·기법별 동작 및 reduced-motion 검사

### 로컬 실행

저장소를 내려받고 `python -m http.server 5173`을 실행한 뒤 브라우저에서 `http://localhost:5173`으로 접속합니다. 외부 JavaScript 빌드 단계나 API 서버는 필요하지 않습니다.

### 배포

GitHub의 **Settings → Pages → Build and deployment → GitHub Actions**를 사용합니다. `main` 브랜치의 파일이 변경되면 자동 테스트 통과 후 GitHub Pages로 배포됩니다.
