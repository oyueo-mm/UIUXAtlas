# UIUXAtlas

> 다양한 UI/UX 디자인 패턴과 애니메이션, 인터랙션 기법을 직접 체험하고 비교할 수 있는 인터랙티브 도감.

**공개 사이트:** https://oyueo-mm.github.io/UIUXAtlas/

네 가지 분류, 총 **36개** 항목을 수록한 첫 버전입니다.

## 주요 기능

- 각 카드에서 CSS/JS 효과 실시간 미리보기
- 상세 패널에서 정의·사용 상황·주의점 학습
- 애니메이션 다시 재생, 재생/정지, 배속 변경
- 한국어·영어 명칭과 키워드 검색
- 카테고리 필터 및 이름순 정렬
- 브라우저에 즐겨찾기 저장
- 반응형 화면과 키보드 접근 지원
- 별도 로그인·서버·빌드 도구 없이 작동

일부 공유 관련 시연은 실제 OS 시스템 공유를 실행하는 대신 **모의 동작**을 사용합니다. QR 미리보기는 설명용 장식이며 실제 스캔용 코드가 아닙니다.

## 로컬 실행

정적 HTML/CSS/JavaScript 프로젝트이므로 별도 의존성이 없습니다.

1. 저장소를 다운로드하거나 클론합니다.
2. 터미널에서 저장소 폴더로 이동합니다.
3. Python이 설치되어 있다면 python -m http.server 5173 명령을 실행합니다.
4. 브라우저에서 http://localhost:5173 으로 엽니다.

## 구조

- index.html — 기본 레이아웃, 사이드바, 검색 영역, 상세 패널
- styles.css — 디자인 시스템, 반응형 스타일, 애니메이션
- app.js — 36개 기법 데이터, 미리보기, 검색·필터·즐겨찾기
- favicon.svg — 로고
- .github/workflows/deploy.yml — GitHub Pages 자동 배포

## 배포

GitHub 저장소의 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 한 번 지정해 주세요. 이후 main에 푸시하면 저장소에 포함된 워크플로가 정적 사이트를 배포합니다.
