# UIUXAtlas

다양한 UI/UX 디자인 패턴과 애니메이션, 인터랙션 기법을 직접 보고, 눌러보고, 비교할 수 있는 인터랙티브 도감.

**공개 사이트:** https://oyueo-mm.github.io/UIUXAtlas/

## v1.1 — 총 144개 UI/UX 기법

기존 v1.0의 36개 항목을 보존하고, 12개 카테고리의 108개 항목을 추가했습니다. **총 16개 카테고리, 144개 기법**입니다.

| 분류 | 항목 수 |
| --- | ---: |
| 텍스트 효과 · 화면 전환 · UI 비교 · 공유 패턴 | 각 9개 (기존 36개) |
| 피드백·상태 · 입력·폼 · 탐색·메뉴 · 제스처 | 각 9개 |
| 스크롤 효과 · 로딩·진행 · 카드 효과 · 오버레이·팝업 | 각 9개 |
| 데이터·표 · 선택·설정 · 마이크로 인터랙션 · 접근성·사용성 | 각 9개 |
| **합계** | **144개** |

### 기능

- 카드에서 자동 반복되는 **144개 개별 UI/UX 미리보기**
- 기법별 이름(한국어·영어), 설명, 적절한 사용 상황, 주의점
- 홈 / 전체 도감 / 카테고리 / 즐겨찾기 **독립 화면**, 브라우저 뒤로 가기 및 직접 링크 지원
- 검색, 카테고리 필터, 이름순 정렬, 즐겨찾기 로컬 저장
- 상세 화면에서 애니메이션 재생·정지·다시 재생·배속 변경
- **34개 대표 기법의 추가 조작 컨트롤**: 스위치, 라디오, 체크박스, 슬라이더, 별점, 색상, 날짜·시간, 표 편집·정렬 등
- 작은 화면용 반응형 UI, 키보드 포커스, 모션 감소 설정 지원
- 화면 밖 카드의 애니메이션을 일시 정지하여 불필요한 실행을 줄임
- 별도의 서버 또는 빌드 도구 없이 정적 웹사이트로 배포

일부 OS 공유 동작·고급 제스처·시스템 인터랙션은 **동작 원리를 보여주는 시연**이며 실제 운영체제 UI 전체를 대체하지 않습니다. 접근성 데모 역시 실제 스크린 리더 또는 보조기술의 검증을 대체하지 않습니다.

### 파일 구성

- `index.html`: 홈과 도감 화면의 구조
- `styles.css`: 기본 레이아웃 및 기존 v1.0 애니메이션
- `app.js`: 화면 이동, 검색, 즐겨찾기, 재생 제어, 도감 통합
- `expansion-data.js`: 12개 추가 분류 및 108개 기법 메타데이터
- `expansion-demos.js`: 추가 기법들의 미리보기 컴포지션
- `expansion-styles.css`: 추가 미리보기 스타일 및 애니메이션
- `expansion-controls.js`: 상세 화면의 직접 실험 컨트롤
- `tests/check-expansion.cjs`: 전체 144개 ID·분류·데모 검증
- `tests/smoke.cjs`: Chrome 브라우저 기능 및 반응형 테스트

### 로컬 실행

저장소를 내려받은 다음 `python -m http.server 5173` 명령으로 서버를 열고, 브라우저에서 `http://localhost:5173`으로 접속합니다.

### GitHub Pages 배포

**Settings → Pages → Build and deployment → Source → GitHub Actions**를 선택하면, `main`에 반영한 코드를 GitHub Actions로 자동 검증하고 배포합니다.
